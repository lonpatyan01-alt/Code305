    اہم بات: پہلی بار انٹرنیٹ ضروری ہے۔

-----------------------------------------------------------------
    پہلا مرحلہ: زپ فائل کو کھولیں
-----------------------------------------------------------------

    1. زپ فائل کو اپنے موبائل میں محفوظ کریں
    2. زیڈ آرکائیور یا کوئی بھی فائل مینیجر کھولیں
    3. ایکسٹریکٹ ہیئر پر کلک کریں
    4. ایک نیا فولڈر بنے گا جس کا نام ہو گا:
       کوڈ 305 الٹرا

-----------------------------------------------------------------
    دوسرا مرحلہ: ایڈیٹر کو کھولیں
-----------------------------------------------------------------

    1. فولڈر میں جائیں
    2. index.html فائل تلاش کریں
    3. اس پر دیر تک دبائیں (لانگ پریس)
    4. اوپن ود پر کلک کریں
    5. کروم منتخب کریں

    نوٹ: اگر کروم نہیں ہے تو پلے اسٹور سے ڈاؤن لوڈ کریں

-----------------------------------------------------------------
    تیسرا مرحلہ: انسٹال بٹن دبائیں
-----------------------------------------------------------------

    1. ایڈیٹر کھلنے کے بعد ایک پاپ اپ آئے گا
    2. انسٹال ایپ یا ایڈ ٹو ہوم اسکرین لکھا ہوگا
    3. اس پر کلک کریں
    4. انسٹال کنفرم کریں

    اگر پاپ اپ نہ آئے تو:
    - کروم میں تین نقطوں والا مینیو کھولیں
    - ایڈ ٹو ہوم اسکرین پر کلک کریں
    - نام رکھیں: کوڈ 305 الٹرا
    - ایڈ پر کلک کریں

-----------------------------------------------------------------
    چوتھا مرحلہ: استعمال شروع کریں
-----------------------------------------------------------------

    1. ہوم اسکرین پر کوڈ 305 کا آئیکن آ جائے گا
    2. آئیکن پر کلک کریں
    3. ایڈیٹر ایپلیکیشن کی طرح کھلے گا

-----------------------------------------------------------------
    پانچواں مرحلہ: آف لائن استعمال کریں
-----------------------------------------------------------------

    ایک بار انسٹال ہونے کے بعد:

    - انٹرنیٹ بند کر دیں
    - ایپلیکیشن پھر بھی کام کرے گی
    - تمام فیچرز دستیاب ہوں گے
    - ہمیشہ کے لیے آف لائن چلے گی
